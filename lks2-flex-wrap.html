Flex: Card Produk + flex-wrap

Tujuan: memahami flex-wrap, efek angka pada flex-basis (bagian flex: 1 1 220px), dan fungsi gap.

Editor & Preview

Ubah kode lalu klik Run.

Eksperimen

  1. Ubah flex-basis kartu
    Lokasi: di CSS pada rule .card { ... }
    Ubah: flex: 1 1 220px; menjadi flex: 1 1 320px;
  2. Matikan wrap
    Lokasi: di rule .list { ... }
    Ubah: flex-wrap: wrap; menjadi flex-wrap: nowrap;
    Catat apa yang terjadi saat layar dipersempit.
  3. Ubah gap
    Lokasi: masih di rule .list { ... }
    Ubah gap: 16px; menjadi 0px lalu 32px.
