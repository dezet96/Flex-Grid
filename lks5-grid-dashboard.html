Grid + Flex: Dashboard Sederhana

Tujuan: membedakan Grid untuk layout halaman (besar) vs Flex untuk isi komponen (kecil).

Editor & Preview

Eksperimen

  1. Ubah lebar sidebar
    Lokasi: rule .page { ... }
    Ubah grid-template-columns: 260px 1fr; menjadi 200px 1fr.
  2. Ubah jumlah kolom card
    Lokasi: rule .cards { ... }
    Ubah repeat(3, 1fr) menjadi repeat(2, 1fr).
  3. Buat card pertama melebar 2 kolom
    Lokasi tempel: tempel di dalam <style>, setelah rule .card { ... } (atau di paling bawah).
    Tempel: .card:first-child { grid-column: span 2; }
  4. Ubah breakpoint
    Lokasi: @media (max-width: 900px) { ... }
    Ubah 900px menjadi 700px, lalu kecilkan layar.
