Grid: Galeri Responsif Otomatis

Tujuan: memahami repeat(auto-fit, minmax(...)) dan konsep span.

Editor & Preview

Eksperimen

  1. Ubah ukuran minimal kolom
    Lokasi: rule .grid { ... }
    Ubah minmax(160px, 1fr) menjadi minmax(240px, 1fr).
  2. Ubah jarak antar item
    Lokasi: rule .grid { ... }
    Ubah gap: 12px; menjadi 24px.
  3. Buat item pertama jadi featured
    Lokasi tempel: di dalam <style>, tempel setelah rule .item { ... } (setelah kurung penutup }).
    Tempel: .item:first-child { grid-column: span 2; grid-row: span 2; }
