Flex: Navbar 3 Bagian (kiri–tengah–kanan)

Tujuan: memahami efek justify-content, align-items, dan eksperimen “menengahkan menu” dengan flex: 1.

Editor & Preview

Eksperimen dilakukan dengan mengubah kode di editor, lalu klik Run dan amati preview.

Eksperimen (jelas ubah/tempe l di mana)

  1. Ubah justify-content
    Lokasi: di CSS pada rule header { ... }
    Ubah baris: justify-content: space-between; menjadi justify-content: center;
  2. Ubah align-items
    Lokasi: masih di rule header { ... }
    Ubah baris: align-items: center; menjadi align-items: flex-start;
  3. Tempel rule nav agar menu “benar-benar” di tengah
    Lokasi tempel: di dalam <style>, tempel setelah blok header { ... } (setelah kurung kurawal penutup })
    Tempel: nav { flex: 1; display: flex; justify-content: center; }

Pertanyaan Konsep

Jawab berdasarkan pengamatanmu.

1) justify-content mengatur posisi pada arah apa (horizontal/vertikal) saat default flex-direction: row?

2) align-items mengatur posisi pada arah apa (horizontal/vertikal) saat default flex-direction: row?

3) Kenapa nav { flex: 1; } membantu menu jadi lebih “tengah”?
