Flex: Layout Halaman + Sidebar Responsive

Tujuan: memahami peran flex: 1 pada layout full tinggi, dan efek breakpoint media query.

Editor & Preview

Eksperimen

  1. Ubah lebar sidebar
    Lokasi: rule aside { ... }
    Ubah width: 240px; menjadi 180px lalu 320px.
  2. Uji fungsi flex: 1 pada .main
    Lokasi: rule .main { ... }
    Hapus baris flex: 1; lalu amati posisi footer.
  3. Ubah breakpoint responsive
    Lokasi: bagian @media (max-width: 700px) { ... }
    Ubah 700px jadi 900px, lalu kecilkan layar.
